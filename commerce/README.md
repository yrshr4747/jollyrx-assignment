# Commerce setup and fallback
Preferred: Creator Deluge sync with only `ZohoCommerce.items.CREATE` and `ZohoCommerce.items.UPDATE`. The payload includes API-required `name`, `url`, and `variants`; the variant uses the masked Node ID as SKU and a zero rate for quote-only behavior. Hide price/cart in the storefront and confirm the theme does so before publishing. [Create product](https://www.zoho.com/commerce/api/create-a-product-with-variant.html) · [Update product](https://www.zoho.com/commerce/api/update-a-product.html) · [Multiple DCs](https://www.zoho.com/commerce/api/multiple-data-centers.html)

Fallback: Commerce > Products > Import, using `products.csv`. This demonstrates masked catalog only; it does **not** implement Creator-to-Commerce sync. Do not import Creator seed data. [UI-ONLY] Create/publish store and products. Ensure only four public attributes and generic title/SEO. If product setup forces visible pricing, verify no API/source exposure before publish.
